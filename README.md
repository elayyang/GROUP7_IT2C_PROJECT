SYSTEM PROCESS SPECIFICATIONS

TITLE: SalonBook: Multi-Service Appointment Scheduling &amp; Client Booking System
USER:
Primary Role/Persona: Salon Receptionist
The receptionist or staff member is responsible for entering client information, selecting
services, checking appointment availability, assigning staff, and managing appointments.
Other users may include salon staff and the business owner.
PROCESSES:
1. View available salon services
2. Select a service
3. Enter client information
4. Select an appointment time
5. Check time-slot availability

6. Assign an available staff member
7. Confirm client reservation
8. View existing appointments
9. Cancel an appointment
10. Exit the system
